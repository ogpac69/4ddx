# 4DDX Phase D3.7–D3.9 consolidated release

Includes analytics parity, on-demand shadow-read comparison, and a guarded structured-read switch. The switch is off by default and refuses activation unless every active questionnaire ID matches and the structured profile validates.

This release does not remove legacy data, change the legacy write target, upload health data, or perform a participant data migration.

See `docs/phase-d/D3.7-D3.9-installation.md` before applying.

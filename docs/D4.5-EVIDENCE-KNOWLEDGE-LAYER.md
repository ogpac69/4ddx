# D4.5 — Evidence & Knowledge Layer

Adds a case-scoped evidence library alongside D4.4. It records source metadata (authors, year, type, URL/DOI, perspective, population/model, methods, limitations and a user-entered appraisal label) and narrowly worded claims linked to a source and optionally to a hypothesis.

## Boundaries
- No web scraping, source verification, automatic literature grading, truth scoring or treatment recommendations.
- Appraisal labels are user-entered. A study design label does not by itself determine certainty.
- Claims must be interpreted in the population, model and context actually studied.
- Mechanistic plausibility is not clinical efficacy.
- Conflicting sources remain visible; the tool does not average disagreement into consensus.
- Evidence data is stored separately per diagnostic case under `bioenergetic_d4_evidence_v1`. Existing profile data and D4.4 case records are not migrated or rewritten.
- Export the evidence library separately from the D4.4 case JSON. Both may contain sensitive health-related information.

## Included
`engine/d4-evidence-library.js`, `engine/d4-evidence-workspace.js`, both HTML entry points, tests and this document.

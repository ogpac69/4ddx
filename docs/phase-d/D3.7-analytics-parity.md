# D3.7 — Analytics parity

D3.7 defines a read-only comparison between active questionnaire IDs in the legacy `assessment` object and structured `assessmentV2.answers`. It compares semantic status and value, not metadata such as provenance or timestamps. Empty legacy strings normalize to `not_answered`; zero and false remain answered values.

The app's current completion index and domain scores are completion indicators, not biological health scores. Parity must not be described as clinical validation. The comparator is pure and does not mutate or persist a profile.

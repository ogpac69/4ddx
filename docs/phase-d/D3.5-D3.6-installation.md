# D3.5 + D3.6 consolidated installation

1. Extract this ZIP at the repository root, preserving paths.
2. Add the new files. Do not replace or delete existing engine files, fixtures, backups, or user data.
3. Run the D3.5 registry sync script from a Node environment to generate `schemas/assessment-question-registry.v2.json`.
4. Run the D3.6 UI patch script from the repository root. It modifies both `index.html` and `app/index.html`; inspect the diff.
5. Run the tests listed below before committing.

Commands:
```sh
node scripts/sync-assessment-registry.js
node scripts/apply-d3.6-ui-integration.js
node tests/node/d3.5-registry-sync.test.js
node tests/node/d3.6-assessment-integration.test.js
node tests/node/d3.2-assessment-data.test.js
node tests/node/d3.3-assessment-bridge.test.js
```

For a Gitling-only workflow, the scripts require a Node runtime. If Gitling cannot run Node scripts, add the engine file and scripts first, then use the generated patch instructions or ask for a manually patched HTML release. Do not enable shadow writes until the new Settings toggle appears and tests pass.

The UI patch is intentionally idempotent and checks all expected anchors before writing. It will refuse to patch if the live source differs from the inspected version.

# D3.9 — Controlled structured-read rollout

Structured reads use a separate localStorage flag, `d3_assessment_v2_read_enabled`, and are disabled by default. Enabling requires a valid structured profile and a passing parity comparison across every active questionnaire ID. The UI asks for explicit confirmation. The legacy assessment object remains the write target and rollback path; the D3.6 shadow-write feature must keep the structured copy current for parity to remain valid after edits.

The “Use legacy reads” control disables the flag and refreshes the visible assessment and completion analytics. If parity fails, enabling is blocked. Do not remove legacy fields or legacy write logic in this phase.

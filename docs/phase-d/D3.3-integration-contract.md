# D3.3 integration contract

- The existing `bioenergetic_profile_v1` localStorage key remains unchanged.
- Legacy `db.assessment` remains the source of truth while the feature flag is off.
- The feature flag key is `d3_assessment_v2_enabled`; absence means disabled.
- The bridge never writes localStorage. Persistence belongs to a later explicit UI integration.
- Migration always returns a pre-migration JSON backup.
- No profile migration occurs on page load.
- Unknown and retired question keys must be preserved.
- Rollback restores the complete pre-migration JSON object, not a partial answer map.
- Analytics parity is required before enabling structured reads.

# D3.8 — Shadow-read comparison

The parity panel runs both representations locally and reports checked, matched and mismatched active question IDs. It does not upload data or store answer values in telemetry. Only mismatch IDs and status labels are rendered in the local diagnostic panel. The comparator is run on demand; no background polling is introduced.

A passing check means the active questionnaire fields currently agree under the normalization rules. It does not prove every export, historical record, chart, or future code path is equivalent.

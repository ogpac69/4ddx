# D3.2 — Assessment data layer implementation

Status: standalone implementation and tests. Not wired into the live app.

## What changed
- Added `engine/d3-assessment-data.js`, browser-global and CommonJS compatible.
- Added additive `assessmentV2` storage while leaving legacy `assessment` untouched.
- Added idempotent migration from `bioenergetic_profile_v1`.
- Added structured answer metadata: status, timestamp, recall window, provenance, confidence, unit, method and notes.
- Added explicit missingness states; numeric zero and boolean false remain valid answers.
- Added safe read/write, opt-in legacy dual-write, validation, and JSON import/export.
- Added legacy and partially migrated fixtures plus migration tests.

## Compatibility decision
The module uses `assessmentV2` instead of replacing `assessment`, because the current app expects primitive values at `db.assessment[questionId]`. Structured writes go to `assessmentV2.answers`. A caller may request `legacyMirror: true` only for a known stable legacy ID.

## Migration behavior
- Existing assessment values and unrelated top-level fields are preserved.
- Raw legacy values are copied once to `assessmentV2.legacy`.
- Existing legacy keys are promoted to structured answers.
- Empty string becomes `not_answered`; numeric zero and boolean false remain `answered`.
- No value is reclassified as `explicit_none` because that meaning cannot safely be inferred.
- Unknown keys survive in the old object and raw snapshot.
- Existing structured answers are not overwritten by repeat migration.
- Migration does not mutate its input and is idempotent.

## Integration boundary
Do not load this module from `app/index.html` until the integration release. No profile is migrated simply by loading the current site.

## API
```js
const D = window.D3AssessmentData;
const migrated = D.migrateProfile(db, { questionIds: ["age", "sex"] });
const answer = D.readAnswer(migrated, "age");
const next = D.writeAnswer(migrated, "age", "21", {
  provenance: "self_report", recallWindow: "current", legacyMirror: true
});
const json = D.exportProfile(next);
const restored = D.importProfile(json);
```

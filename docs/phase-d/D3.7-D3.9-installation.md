# D3.7–D3.9 installation

1. Extract this ZIP at the repository root, preserving paths.
2. Confirm `engine/d3-assessment-data.js` and `engine/d3-assessment-bridge.js` are already present (they are prerequisites from D3.2/D3.3).
3. Run `node scripts/apply-d3.7-d3.9-ui.js` from the repository root. It patches both `index.html` and `app/index.html`, and refuses if expected anchors are absent.
4. Run `node tests/node/d3.7-d3.9-rollout.test.js`.
5. Commit and push the changed files. The ZIP itself does not deploy the site.

On the live site, open Settings → Assessment read parity & rollout. Run parity first. If it fails, do not enable structured reads. If it passes and the structured shadow-write path is active, you may explicitly enable reads. “Use legacy reads” is the rollback control.

The patch keeps writes on `db.assessment`; it only changes the named read consumers. Back up your repository files before running the patch. No local participant profile is migrated by installing these files.

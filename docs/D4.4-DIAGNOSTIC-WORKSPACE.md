# D4.4 — Diagnostic Workspace UI

Adds a user-guided case workspace to both app entry points. Cases are stored separately under `bioenergetic_d4_diagnostic_cases_v1`; the existing profile database and JSON import/export are untouched.

Users can create cases, record a problem representation, observations and safety notes, add multiple hypotheses, distinguish mainstream clinical from Peat/Ling-inspired perspectives, classify evidence, and record supporting/contradicting observations, confounders, predictions, falsifiers, missing data and source notes. A case can be exported as its own JSON file.

No automated diagnosis, probability, ranking, triage or treatment advice is generated. Evidence labels are user-entered. Empty red-flag lists do not establish safety. This is documentation software, not a clinically validated diagnostic system.

Storage is local to the browser/device. Exported case files may contain sensitive health information; store and share them accordingly. No migration is performed.
